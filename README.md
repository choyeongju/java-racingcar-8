# java-racingcar-precourse
### 사용자 입력

- 자동차 이름 입력 받기
    - 안내 문구 출력: 경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
    - Console.readLine()로 사용자 입력값 수집
    - 경주할 자동차 이름 파싱: 쉼표(,)를 기준으로 분리, 각 이름 trim() 적용
- 시도 횟수 입력 받기
    - 안내 문구 출력: 시도할 횟수는 몇 회인가요?
    - Console.readLine()로 사용자 입력값 수집
    - 시도 횟수 파싱: 정수 변환 (예외 케이스 처리)
- null 또는 공백만 입력 시 `IllegalArgumentException`
- 중복되는 자동차 이름을 입력할 시 `IllegalArgumentException`

### **게임 진행로직**

- 라운드 n회 반복
    - 자동차별 이동 거리 0으로 초기화
    - 각 자동차에 대해 0~9 난수 생성 (Randoms.pickNumberInRange(0, 9))
    - 난수가 4 이상이면 전진, 아니면 정지
    - 차수별 실행 결과 출력
        - <이름> : <'-' * 이동거리> 형식

### **출력 형식**

- 차수별 결과는 각 라운드마다 자동차별 한 줄씩 출력
    - <이름> : <'-' * 이동거리> 형식
- 라운드 사이 빈 줄 출력
- 최종 우승자 라인 출력 전 빈 줄 한 줄

### 예외 처리 

- 사용자의 입력 오류일 경우에는 `IllegalArgumentException` 발생시킴
    - [400] 이름은 5자 이하만 가능합니다
    - [400] 빈 이름은 허용되지 않습니다.
    - [400] 시도 횟수는 1 이상의 정수여야 합니다.
    - [400] 정수를 입력하세요.
